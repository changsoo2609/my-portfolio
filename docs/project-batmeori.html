프로젝트가 풀려던 문제

농장주의 구두 지시에는 작업 순서와 수량, 장소가 함께 들어갑니다. 팀은 작업 내용을 구조화하고 근로자가 자기 언어로 확인할 수 있는 흐름을 만들었습니다.

맡은 일과 검증

1박 2일 일정에 맞춰 기능 범위를 줄이는 기획에 참여했고, FastAPI·Supabase 기반 백엔드와 PyTest 검증을 맡았습니다. 솔버톤 최우수상은 팀 성과입니다.
