프로젝트가 풀려던 문제

부모가 미션을 등록하고 아이가 사진이나 영상으로 인증합니다. 부모의 승인 후 아이는 보상을 받아 펫을 성장시킵니다.

맡은 일과 검증

부모와 아이의 화면, 미션 인증 UI, 보상 및 펫 화면을 구현했습니다. 팀 README에는 영상 화면을 다시 그릴 때 선택 상태가 초기화되는 문제를 UI 상태 분리로 해결한 사례가 기록되어 있습니다.
